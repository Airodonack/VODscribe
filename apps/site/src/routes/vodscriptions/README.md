# /vodscriptions

The page for streamers and whoever pays for a channel.

- `+page.svelte`: the page: the demo, what a VODscription holds, and sign-up.
- `OfferDemo.svelte`: the demo opened on the NASA VOD with its VODscription.
- `ComingSoon.svelte`: a sign-in button that can't be pressed yet, and an email to join the waiting list.
- `PlatformMark.svelte`: Twitch's, YouTube's and Kick's marks, for "works with".
