# The page

The app's interface, a SvelteKit single page built statically into the app.

- `app.html`: the HTML shell.
- `app.css`: the colours, light and dark, and the styles every view shares.
- `hooks.client.ts`: loads the choices the page remembers before anything else starts.
- [`lib`](lib): the components and modules.
- [`routes`](routes): the one page.
