# Emote provider logos

The logos of the chat emote providers Settings → Appearance can turn on
(EmoteProviders.svelte), to show which service each button is. They are the
providers' trademarks, used only to name them; VODscribe isn't affiliated
with them.

- `bttv.png`: BetterTTV's site icon, from https://betterttv.com/favicon.png
- `ffz.png`: FrankerFaceZ's site icon, from https://www.frankerfacez.com/static/images/favicon-32.png
- 7TV's is drawn inline in EmoteProviders.svelte, from https://7tv.app/favicon.svg (black, or white in dark mode, as 7TV draws it).

Taken October 2026.
