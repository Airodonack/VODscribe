# Test fixtures

- `eagle-has-landed.mp3`: Apollo 11's landing ("Houston, Tranquility Base here. The Eagle has landed."), 5 seconds. NASA, public domain. From [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Apollo_11_Eagle_Has_Landed.mp3), originally [nasa.gov](https://www.nasa.gov/connect/sounds/index.html).
- `library-0.3.0.sqlite`, `settings-0.3.0.json`: a library and settings as VODscribe 0.3.0 left them (the landing above, transcribed; the dark theme), for the upgrade scenario. Made by `make-old-library.mjs` driving the 0.3.0 release; the file's folder is the placeholder `{FIXTURES}`.
- `library-0.5.0.sqlite`, `settings-0.5.0.json`: the same as 0.5.0 left them, with ten minutes of the landing looped (`longSpeech`) paused part-way through transcribing, for the upgrade-0.5.0 scenario. Made by `make-old-library.mjs` driving CI's 0.5.0 Linux build; the looped file's folder is the placeholder `{SPEECH}`.
- `library-0.4.0.sqlite`, `library-0.5.1.sqlite`, `library-0.5.2-dev.sqlite` and their `settings-<version>.json`: the upgrade matrix (`scenarios/upgrade-<version>.mjs`, checks in `upgrade-matrix.mjs`). Each has four VODs (a file, YouTube, Twitch, and a paused Kick one), transcripts with words, chat with authors, clips, marks, and two edits with pieces (from 0.5, one with a group); 0.5.2-dev has stretches as the development build kept them. Made by `make-matrix-library.mjs <version>`, which builds the schema from that release's own migrations in git (db.rs at the tag; 0.5.2-dev is 4bdb439) and fills it with rows in the shape of format 21, upgraded by those migrations as a user's library was; the files' folder is the placeholder `{FIXTURES}`. 0.4.1 left no scenario of its own: its library format and settings are 0.4.0's, and 0.5.1's are 0.5.0's. Add a version to `RELEASES` in `make-matrix-library.mjs` and a scenario file when a release changes either.
