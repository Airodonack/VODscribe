# Chat replays' tests

- `tests.rs`: the files in `tests/` that hold the specs of `chat.rs`.
- `tests/parse.rs`: what each site's chat says, read: times, emotes, subs, gifts and tips, and when the VOD started.
- `tests/fetch.rs`: fetching a chat: slices, carrying on where it stopped, pages asked again, YouTube's file as yt-dlp writes it.
