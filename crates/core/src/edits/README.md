# Edits' tests

- `tests.rs`: the helpers the specs of `edits.rs` share, and the files in `tests/` that hold them.
- `tests/document.rs`: an edit's pieces and groups, split, trimmed, moved and taken out; its marks, clip bar and undo.
- `tests/render.rs`: what an edit's file is made of, and whether it's of the edit as it is.
