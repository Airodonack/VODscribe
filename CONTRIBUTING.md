# Contributing

Bug reports and ideas go in the [issue tracker](https://github.com/Airodonack/VODscribe/issues). For a security problem, see [SECURITY.md](SECURITY.md) instead.

## Changes

Small fixes are welcome as pull requests. For anything larger, open an issue first so the work isn't wasted on a direction the project won't take.

The README describes the layout and how to build. Formatting is enforced: `cargo fmt` and Prettier, through the pre-commit hook and CI (`.github/workflows/check.yml`), which also runs clippy and the tests. Comments say why, not what; commit messages are full sentences that say what changed and why.
